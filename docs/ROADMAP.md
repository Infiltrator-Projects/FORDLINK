# Roadmap

This roadmap describes direction, not dates. Current support is whatever the tested source actually implements.

## Current foundation

- maintain the Ford network/module data model and bounded read-only manufacturer scanner
- keep standard diagnostics inherited from LINK
- exercise module/network/procedure/signal behaviour in product tests

## Near-term priorities

- expand module and network evidence from verified vehicles and sources
- add manufacturer signals/procedures only with clear provenance and safety classification
- keep shared navigation and diagnostic flow in LINK

## Longer-term direction

- broaden vehicle-platform coverage and adapter-aware network switching
- add enhanced functions only when physical network access and expected responses can be validated

## Admission rule

New work needs clear ownership and a realistic validation path. Research or inspiration is not itself an implementation commitment.

## Completion rule

An item is complete only when implementation, regression evidence, user-visible behaviour and maintained documentation agree.
